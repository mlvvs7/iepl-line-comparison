## 先分清：IEPL、IPLC 和“优化线路”差在哪

一句话说清三者关系：IEPL 和 IPLC 都是点对点专线，流量从国内入口进入专线内网传输，到境外出口再上公网，中间不经过拥挤的国际出口；CN2 GIA、联通 CUG、移动 CMI 这类“优化线路”本质仍是公网，只是路由选得更好。差别直接体现在延迟和价格上。

以 MKCloud 为例，广港 IEPL 的入口走 UCloud 广州八线动态 BGP 或三大运营商线路，出口是香港 BGP，端到端延迟 3ms 以内——这个数字意味着在广州、深圳访问香港服务器，体感接近访问本地机房。优化线路平时延迟也不错，但晚高峰和国际出口拥堵时依然会波动，这是物理架构决定的，跟商家调不调路由没关系。

价格差距同样来自这里。专线按带宽和传输成本实打实计费，同样配置下 IEPL 套餐普遍比优化线路 VPS 贵一截。你要为延迟和稳定付钱，还是为便宜付钱，想清楚这一点，后面的选择会简单很多。
